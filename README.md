# Atividade Avaliativa — Seletores e Manipulação do DOM
 
Repositório com a resolução da atividade avaliativa sobre **seletores do DOM em JavaScript**. Cada exercício é uma página HTML independente que demonstra, na prática, como selecionar elementos, reagir a eventos e alterar o conteúdo, o estilo e os atributos da página.
---
 
📌 Projeto desenvolvido para fins educacionais como atividade avaliativa.
